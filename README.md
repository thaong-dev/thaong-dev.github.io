# Thaong Dev - Mobile Camera & Barcode Solutions

Welcome to the official repository for **Thaong Dev** (`thaong-dev.github.io`). 

We specialize in building high-performance, offline-first mobile applications focused on optical recognition, real-time camera processing, and industrial-grade barcode/QR decoding.

## 🌐 Official Website
Visit our developer landing page: **[https://thaong-dev.github.io](https://thaong-dev.github.io)**

## 🚀 Core Focus
- **High-Speed Barcode & QR Scanning:** Fast, accurate 1D/2D barcode recognition powered by native C++ processing.
- **Smart Camera Utilities:** Real-time image preprocessing, optical character recognition (OCR), and custom camera pipelines.
- **Offline-First & Data Utility:** Reliable local data processing and exporting without relying on cloud connectivity.
- **Privacy-Centric:** 100% on-device camera frame processing. No personal data or camera images leave the user's device.
